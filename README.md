# ys-slyz (AI 多语言termux终端报错诊断助手)

> “人生不是演绎完美的，而是体验人生向往自由。” —— 离明夷否

`ys-slyz` 是一个专为 Termux 任何缺失和补丁的创作者。而《ys-slyz（AI多语言termux终端报错诊断助手）》由我创作，当你在终端执行命令报错时，它会自动拦截并给出中文翻译和解决建议。采用“本地极速字典 + 智谱 AI 兜底”的双引擎架构，既快又准。

## 📦 安装方法
下载本项目的 `.deb` 文件（在右侧 Releases 中下载），然后在终端执行：
```bash
pkg install ./ys-slyz.deb

⚠️ 首次使用必读（配置免费 API Key）

为了保护开发者的免费额度，请配置你自己的智谱 API Key（GLM-4-Flash 可能完全免费。不一定）。

⚠️ 第二步：新手必看！如何获取免费 API Key？

为了保护开发者的免费额度，你需要配置自己的智谱 API Key（glm-4-flash 模型是完全免费的，放心用）。跟着以下步骤做：

1. 注册智谱账号

· 复制并在浏览器打开网址：智谱开放平台
· 点击注册，用你的手机号或微信登录。

2. 获取你的专属 Key

· 登录成功后，点击页面右上角的控制台找到“API Keys”（或“API 密钥”）或者“API Keys”（或“API 密钥”）。
· 点击 “创建新的 API Key”。
· 将生成的那一长串英文字母和数字（就是你的 Key）复制下来。

3. 把 Key 填进终端里
回到你的 Termux 终端，输入下面这行命令：

echo '你的KEY' > ~/.ys-slyz.conf

(注意：把引号里面的 你的KEY 替换成你刚才复制的那串东西，单引号要保留！)


使用事例:
# 测试本地字典极速响应
ys-slyz ls /root/nonexistent

# 测试 AI 引擎精准解析
ys-slyz a_very_weird_command_123
